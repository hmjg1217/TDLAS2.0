# 第三步验收记录：主窗口 UI 完善

日期：2026-10-27。工程：TDLAS2.0。按《实施计划》第 3 步完成主窗口布局、参数/页面、主题、空态、尺寸缩放和滚动的补齐与验收。第二步已经提前实现结果绑定，基础框架已经包含布局，本轮在其上修正实际缺口；没有接入 TDLASProcessor。

## 完成内容

1. 保持 11 个参数的名称、顺序和永久标签；A/B/C、20/80 双栏、四选项卡、调试页 2×2 外框顺序保持一致。
2. 明确 Tab 顺序：参数→采集控制→主题→选项卡。焦点变化由内向外滚动各层容器，显示整个控件及边框。新增测试发现 Qt 默认只显示编辑光标、控件底边仍被裁切，现已修复。900×600 小窗口同样验证字段、控制和表格入口可达。
3. 输入量程上限不大于下限时，两字段标红并显示文字原因，开始禁用；修正后恢复。错误和禁用原因附辅助技术描述。模拟源没有输出能力，相关参数继续禁用并明确原因，不伪造设备能力。
4. 峰值页新增“收起/展开数据表”，保持曲线为主、表格同源，不清空记录。摄像四项入口保持独立禁用并附原因。
5. 图表状态取消固定高度限制，允许长时间/质量说明换行。拟合用独立主题颜色及虚线，峰值历史使用峰值配色，主题切换后样式保持；同一观测曲线被无效点分段后图例不再重复。
6. 增加原生截图入口 tools/ui-smoke.ps1，保存四页日夜空态和合成结果截图、实际内容尺寸/DPI 与 JUnit 报告。数据夹具仅用于 ui_test，产品模拟源仍只输出原始电压。

## 布局与截图核对

五种内容视口均在 100%/125%/150%/200% Qt 缩放下测试，按实际逻辑尺寸断言。四图外框宽高差不超过 1 逻辑像素，顺序保持左上原始、右上拟合、左下 FV、右下历史。全部尺寸和倍率记录在 artifacts/{debug,release}/ui/geometry.json 与 ui-scale-*/geometry.json。

| 内容视口 | 主区宽 | 左/右列宽 | 行为 |
|---|---:|---|---|
| 1920×1080 | 1920 | 384 / 1536 | 20/80，四图约 744×446 |
| 1600×900 | 1600 | 320 / 1280 | 20/80 |
| 1440×900 | 1440 | 288 / 1152 | 标签在控件上方，侧栏滚动 |
| 1366×768 | 1440 | 288 / 1152 | 外层横向滚动，保留 2×2 |

本机原生最大化内容尺寸为 **1536×793 逻辑像素，DPR 1.25**，不能将其截图称作 1920×1080 内容视口。已目视核对原生客户页空态、调试页日间空态及夜间合成拟合结果；四页完整截图均保存。offscreen 字体渲染存在差异，主要用于几何验证；不是所有实际显示器 DPI 和字体的验收。

## 验收边界与下一步

本轮第三步范围通过，UI_SPEC 的完整系统清单仍未全部通过：

- 完整图表缩放/拖拽/自动跟随/悬停/键盘选点仍属于第 7 步；已有“复位缩放”入口不代表这些交互已实现。
- 数值框保留原有 Qt 输入范围约束；实际设备能力、设备刷新、离散档位以及更完整的字段编辑策略须随设备后端实现。
- 已测试参数→控制→主题的 Tab 导航、方向键切页、Space 折叠表格和焦点滚动；未宣称完成读屏认证、最终像素对比度测量、所有确认弹窗及所有屏幕组合验收。
- 无效/未校准/停止状态由第二步通路继续提供；按预期物理批次间隔判断陈旧仍待算法节奏确认。
- TDLAS 算法、CSV/JSON、磁盘归档、真实 NI、摄像会话和保存仍未实现。合成夹具通过不代表测量准确度。
- 保留可选 Vulkan 头文件提示及 windeployqt 的 dxcompiler/dxil 自动查找警告；既有部署脚本从 SDK 补齐并校验，最终发布包独立启动已通过。

下一轮按实施计划第 4 步补齐模拟后端和状态机验收；第 6 步算法迁移仍需明确 FV 定义/单位、批次周期、光强参考、频率及浓度标定。旧 v1.5/v1.6 源码、参考资料和用户已有改动未修改。

## 复现与运行

在 TDLAS2.0 内执行：

```powershell
.\Build-Debug.cmd --no-pause
.\Build-Release.cmd --no-pause
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/smoke.ps1 -Configuration Debug
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/smoke.ps1 -Configuration Release -Package
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/ui-smoke.ps1 -Configuration Debug
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/ui-smoke.ps1 -Configuration Release
```

启动开发版：Run-Debug.cmd。启动发布版：artifacts/release-package/tdlas_app.exe，搬运时保留整个发布包目录。
