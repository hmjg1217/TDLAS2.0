# 第四步验收记录：模拟后端与状态机

日期：2026-10-28。工程：TDLAS2.0。按《实施计划》第 4 步，在已有基础框架上完善模拟源、开始/停止/复位、防重入和故障注入，并完成硬件无关验收。本轮未接入 NI、TDLASProcessor、存储或摄像。

## 完成内容

1. 模拟源只接受 `simulation` / `simulation/voltage`，声明软件支持的 1～1000000 Sa/s、−10～10 V 输入配置范围，无 AO 能力；打开时验证配置、会话标识及诊断选项。这里的范围是模拟实现约束，不是对真实采集卡能力的推断。
2. 电压保持确定性：`V[n] = 0.7 × sin(2π × 10 × n / sampleRateHz)`。每个新会话从 n=0 开始，块间连续；显示窗口和处理窗口不改变样本值。序号从 0 递增，携带 runId、设备/通道、配置修订、UTC 和单调时间。
3. `SimulationOptions` 支持打开失败、成功返回指定块数后读取失败、0～10000 ms 的可取消读取延迟。等待调度时每 5 ms 检查停止，生成大块时也检查停止；close 可重复调用，close 后允许重新 open，read-before-open 明确报错。
4. 调试页底部增加“模拟验证场景（非测量）”：正常电压、打开失败、3 块后读取失败、每次读取延迟 1 秒。默认正常，选择不会自动采集，只对下次手动启动生效；运行期间禁止切换，复位恢复正常。保持 11 个采集参数、20/80 双栏及原有 2×2 四图顺序。
5. Starting 期间允许停止；运行及排空期间禁止重入/复位，重复停止不重复完成通知；取消启动后不再跳回 Running。故障检测后立即进入 Error，保留诊断并等待安全退出，stopped 信号到达后刷新控件，使复位/重新开始可用。
6. 未保存确认从 Runtime 已接收样本和结果缓存判断，不再依赖曲线或表格是否已经刷新。默认选“否”，取消不清数据；确认复位清空样本、批次历史、指标和统计，保留采集参数。界面明确说明保存功能尚未接入。
7. 新会话获准启动后立即清除旧原始曲线，等待首块期间显示等待状态；打开失败显示无有效数据。显示快照补充 runId，刷新判断同时比较会话和块序号。停止或读取失败后仍保留最后原始曲线，未知指标不补零。

## 状态与确认语义

正常流程为 `Ready → Starting → Running → StopRequested → Draining → Stopped`，工作线程完成顺序可能使 Draining 被跳过。Starting 可直接取消；Error 既可能表示仍在清理，也可能表示后台已退出，必须结合 active()/stopped() 判断，不能仅凭 Error 销毁工作线程。

无数据复位不弹窗；有数据复位确认清空全部缓存会话。有数据开始新会话时，确认替换原始曲线和采集统计，已有完整批次历史保留。程序当前没有保存接口，缓存数据均视为未保存。复位不会删除磁盘文件。

既有异步关闭、5 秒停止超时及不使用 terminate 的策略保留。第五步将继续系统验收慢处理、队列压力、终态观测和关闭顺序，本轮不宣称该步骤全部完成。

## 使用与复现

1. 双击 Run-Debug.cmd，或运行 artifacts/release-package/tdlas_app.exe。
2. 选择“模拟数据源（非测量）”，点击开始；调试页显示原始电压，吸光度/光强仍为“—”，浓度为“未校准”，不生成 FV 历史。
3. 停止后保留原始曲线。重新开始或复位时按确认框操作。
4. 要验证故障，在停止状态选择调试页底部场景，再手动开始。3 块后失败保留已接收数据；打开失败无新数据；延迟读取可由停止取消。

在 TDLAS2.0 内执行：

```powershell
.\Build-Debug.cmd --no-pause
.\Build-Release.cmd --no-pause
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/smoke.ps1 -Configuration Debug
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/smoke.ps1 -Configuration Release -Package
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/ui-smoke.ps1 -Configuration Debug -Step 4
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/ui-smoke.ps1 -Configuration Release -Step 4
```

## 边界与后续

- 模拟曲线固定为 10 Hz、0.7 V 峰值，输出参数禁用；输入量程仅作配置验证，不模拟 ADC 饱和、量化、噪声或真实驱动时序。首块立即可用，其后按块点数/采样率调度，操作系统调度不保证实时精度。
- 故障注入针对软件源的打开/读取阶段，不等同于真实 NI 断线、驱动异常或硬件安全验收。原有处理失败/队列满/停止超时测试继续通过，进一步压力验收属于第五步。
- 没有迁入测氢算法或保存功能；确定性与 UI 测试通过不代表测量准确度。算法所需 FV 定义、批次规则、光强参考、频率及浓度标定仍待第六步明确。
- 下一轮按实施计划第五步推进。旧 v1.5/v1.6、参考资料和工作区原有修改未改动。
