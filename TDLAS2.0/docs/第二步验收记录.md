## 完成内容

1. 补充 BatchExtent、可选逐点质量、气体/校准元数据、配置窗口预算和 DeviceCapabilities 校验接口；字段与单位详见 [第二步数据契约](第二步数据契约.md)。
2. 新增 ResultHistory：按 `(runId, acquisitionId)` 去重、同序号冲突报错、乱序归位、无效/未标定/空批次 null、负峰值和最早并列点、跨会话/缺号/单位变化断线。
3. Runtime 新增完整结果处理回调，直接从处理线程提交结果；无需 UI 逐批次转发。新会话保留旧历史并清空当前指标，停止保留结果，复位清除全部缓存会话。
4. 客户页与左栏指标、两处 FV、两处峰值历史和表格绑定共同快照；拟合失败只显示本批次观测，浓度无有效校准保持“未校准”。表格包含会话、批次、本地时间、经过秒、峰值、峰值坐标、单位和质量原因。
5. 完整结果缓存容量达到上限时明确报错停源，保留已经接收的数据；不静默覆盖。移除切换数据源时隐式清空错误态结果的行为。
6. 原生截图检查后修正坐标刻度有效数字不足造成的相邻刻度重名；维持既有 11 参数、20/80、四页、2×2 和双主题布局。

## 未完成项与下一步

- 当前程序的模拟源只输出原始电压，因此正常启动和模拟采集时，FV、拟合、峰值历史和测量指标仍为空。新增通路由独立测试夹具验证，不在产品内伪造测氢结果。
- FV 定义与单位、物理批次/周期平均规则、光强参考、频率标定和浓度反演/校准仍待确认；下一步在明确这些契约后迁入并验证 TDLASProcessor。
- 设备能力校验仅是接口与合成测试，尚未做 NI discovery、离散档位、接线模式或真实 AO 范围确认。
- 当前最多保留 2000 个完整批次和 2,000,000 个曲线坐标对预算；满后报错停止。CSV/JSON、后台存储、磁盘失败和存储关闭确认仍未实现。
- 图表完整缩放/悬停/键盘选点、自动跟随、明确陈旧阈值、全部可访问性和真实设备验收仍留后续步骤。
