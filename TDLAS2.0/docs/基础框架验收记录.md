| NI AI/AO、摄像头 | 未访问 | 本轮程序没有相应后端实现，测试只使用模拟源 |

部署期间发现一次不完整的 Qt6Charts.dll；已通过强制刷新修复，并增加二进制完整性检查。windeployqt 的 dxcompiler/dxil 自动查找警告仍可能出现在日志中，脚本随后从已安装 Windows SDK 复制这两个文件并检查 PE 头。最终发布包已实际启动成功。CMake 的可选 Vulkan 头文件提示不影响当前 Widgets/Charts 构建。

复现命令（在 TDLAS2.0 内）：

```powershell
.\Build-Debug.cmd --no-pause
.\Build-Release.cmd --no-pause
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/smoke.ps1 -Configuration Debug
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/smoke.ps1 -Configuration Release -Package
```

smoke 脚本仅最大化启动、保存截图和退出，不点击开始、不输出 AO；20 秒未返回会报告启动失败并结束该次无硬件自检进程。

## 硬件无关测试

- contracts_and_router：设备/通道空值、非有限参数、量程关系、AO 范围、AI-only、缓冲约束；正值/负值/NaN/空批次峰值；并列峰值最早位置；有界队列、拒收和排空。
- runtime_lifecycle：异步停止返回、重复启动拒绝、排空计数核对、再次启动、满队列明确报错且事件循环继续、源启动失败清理、处理异常计数、5 秒停止超时不误报已停止。
- ui_structure：11 参数、四页顺序、无源禁用开始、切页不停止模拟、模拟运行安全关闭、列宽和 2×2 图框尺寸、主题截图。
- ui_scale_1.25、ui_scale_1.5、ui_scale_2：在对应 Qt 缩放倍率下复查尺寸、比例和主题布局。

UI 几何测试使用 Qt offscreen 平台，避免 Windows 桌面大小把请求窗口尺寸裁小；真实窗口启动另用 windows 平台验证。offscreen 的字体渲染与 Windows 原生字体引擎不同，其截图用于几何/颜色核对，不等同于所有原生 DPI、字体和可访问性已验收。

## 内容尺寸记录

四个缩放倍率各请求 1920×1080、1600×900、1440×900、1366×768、2560×1440；测试断言实际内容尺寸等于请求尺寸。数据见 artifacts/debug/ui/geometry.json 及 ui-scale-*/geometry.json，Release 目录同样记录。

| 内容视口 | 主工作区宽 | 左列 | 右列 | 行为 |
|---|---:|---:|---:|---|
| 1920×1080 | 1920 | 384 | 1536 | 20/80，调试四图尺寸一致 |
| 1600×900 | 1600 | 320 | 1280 | 20/80 |
| 1440×900 | 1440 | 288 | 1152 | 标签位于控件上方，左侧可滚动 |
| 1366×768 | 1440 | 288 | 1152 | 保持最小内容宽度，外层横向滚动 |
| 2560×1440 | 2560 | 512 | 2048 | 20/80 |

每张截图的实际物理像素尺寸还受 devicePixelRatio 影响；geometry.json 同时记录逻辑尺寸和倍率，不把 2400×1350 的截图误称为 1920×1080 物理屏幕。
