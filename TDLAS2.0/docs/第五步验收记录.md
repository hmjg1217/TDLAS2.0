# 第五步验收记录：Runtime、队列与异步关闭

日期：2026-10-28。工程：TDLAS2.0。按《实施计划》第 5 步，在第四步模拟后端与状态机基础上完成慢处理、队列压力、输入终态、观测指标和关闭顺序验收。本轮没有接入 NI、旧 TDLASProcessor、存储或摄像，也没有访问真实硬件。

## 完成内容

1. `RouterStats` 新增已接收/成功/失败点数、排队块数、正在处理块/点以及块/点高水位。单处理线程一次最多持有一个处理中块；没有对应处理中块时拒绝重复完成记账。
2. 运行中同时核对块与点的守恒关系：`accepted = queued + processing + processed + failed`。处理线程全部退出后，排队和处理中必须归零，终态为 `accepted = processed + failed`；拒收另计，不混入已接收终态。
3. 队列容量语义不变：只限制等待处理的完整块点数，不包含单个正在处理块、数据源正在生成块或显示快照。溢出拒收当前块、关闭输入、保留已接收块并排空，不静默覆盖。
4. Runtime 新增只读关闭快照：停止已请求、数据源已释放、路由输入已关闭、处理已排空、停止已超时，以及三个阶段的单调顺序号。正常终态要求 `sourceClosedOrder < inputCloseOrder < processingDrainedOrder`。
5. 停止发生在 Draining 时保持排空语义，不倒退显示为一般停止。5 秒超时不伪报 Stopped、不销毁活动线程、不允许复位；同一停止过程重复请求不会重复计时或重复报错，原有故障原因会保留并追加超时说明。
6. 侧栏诊断显示输入/终态块与点、排队/处理中、高水位、拒收/失败、终态核对和关闭阶段。显示定时器仍只读取快照，不接收逐块信号，也不决定算法输入或结果历史。
7. 原生 UI 慢关闭测试把处理器保持在首块，确认窗口忽略立即关闭、主事件循环继续推进、诊断显示 1 个处理中块和正在排空；释放处理器后才发 stopped 并完成关闭。

## 压力与终态语义

受控慢处理输入为 8 块、每块 1000 点、等待队列容量 8000 点。首块被处理线程持有时，稳定观测到 1 块/1000 点处理中和 7 块/7000 点排队；调度先后会使历史高水位为 7 或 8 块，但不会超过配置容量。释放后 8 块/8000 点全部进入成功终态，排队与处理中归零。

队列满测试把容量设为 1000 点并使用快速突发源、慢处理器。当前溢出块明确计为 1 个拒收，全部已接收块仍完成处理，块/点终态均完整。处理器注入异常时，异常块和随后已接受块进入失败终态，已接收块/点仍与成功加失败相等。

聚合终态用于在线观测和停止核对，不是无限增长的逐块审计日志。逐块样本范围、故障区间和磁盘审计需在后续存储策略中使用有界方案，不能为满足观测而无界保留每个块对象。

## 使用与复现

正常用户操作与第四步相同，不新增自动采集或压力模式。第五步的慢处理和队列满均为测试进程内合成夹具，不出现在产品界面，也不访问硬件。

在 TDLAS2.0 内执行：

```powershell
.\Build-Debug.cmd --no-pause
.\Build-Release.cmd --no-pause
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/ui-smoke.ps1 -Configuration Debug -Step 5
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/ui-smoke.ps1 -Configuration Release -Step 5
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/smoke.ps1 -Configuration Debug
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/smoke.ps1 -Configuration Release -Package
```

## 边界与后续

- 第五步证明的是线程隔离、软件队列边界、聚合终态和可取消模拟源下的关闭行为，不代表真实 NI 驱动在断线或阻塞时一定能按时返回。NI 实机生命周期仍需第 8 步及用户明确授权验证。
- Runtime 处理回调仍不计算测氢结果；模拟原始电压没有被冒充为 FV、吸光度、光强或浓度。
- 没有磁盘写入队列或逐块持久化审计，长时间归档容量仍需第 7 步根据吞吐和磁盘预算确定。
- 下一轮按实施计划第 6 步审查并迁入旧 TDLASProcessor。开始前仍需明确 FV、批次边界、光强参考、频率标定和浓度公式；无法确认的物理语义保持显式未确认。
