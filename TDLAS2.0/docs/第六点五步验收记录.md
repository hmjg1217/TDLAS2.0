# 第 6.5 步验收记录：样图视觉对齐与角色入口

日期：2026-10-28。工程：TDLAS2.0。本步依据根目录 `UI/` 中 7 张样图修正第 3 步只完成结构规范、未覆盖产品视觉稿的问题。本步只改界面与启动流程，保留既有 Runtime、数据契约、算法适配和线程边界；未访问 NI 或摄像硬件。

## 完成内容

1. 新增正常启动流程：登录页 → 启动缓存页 → 最大化主窗口。`--smoke-test` 继续绕过交互入口，供无硬件自动启动检查使用。
2. 登录页按样图重建蓝白背景、品牌区、产品标题、账号/密码、角色选择和登录卡片；启动缓存页提供独立品牌画面和载入反馈。视觉均由 Qt 原生绘制和控件组成，不用整张效果图冒充可操作界面。
3. 登录角色分为“管理员工作台”和“客户显示工作台”。管理员保留四个选项卡；客户只显示“摄像窗口 + FV 曲线 + FV 历史”的客户工作台并隐藏管理页入口。
4. 登录当前只创建本地界面会话，不验证真实账号。界面持续显示“认证服务待接入”；“记住账号”禁用。角色隐藏属于界面导航，不是安全权限边界。
5. 主界面改为样图方向的品牌状态栏、实时日期时间、系统状态、账户和主题入口；侧栏标题调整为 A 数据输入、B 采集控制、C 数据监测，采集按钮改为绿/红/蓝横排，三个指标改为并排监测卡。
6. 管理员客户页改为上方摄像/FV、下方 FV 历史；调试页继续保持 2×2；峰值页和摄像页补齐样图式工具区、大预览区和大按钮。摄像未接入时只显示明确空态，不显示伪造现场画面。
7. 日间主题改为浅蓝白卡片、蓝色活动页签和蓝色曲线体系；夜间主题继续保留。原有 20/80、11 参数顺序、四页顺序、键盘焦点、滚动和不同缩放检查保留。

## 边界与后续

- 本步完成的是可操作界面和角色导航，不是账号认证、授权或凭据安全存储；这些需要单独的产品与安全需求。
- 摄像页和客户页的摄像区仍是空态。第 9 步接入 CameraSession 前不会自动请求权限或伪造实时图像。
- 样图中的测量数值、现场照片、浓度和拟合曲线未复制成产品数据。没有有效结果时继续显示“—/未校准”。
- 第 7 步继续实现图表缩放、拖拽、悬停、完整峰值历史交互、CSV/JSON 与异步存储；新功能在本步界面上增量完成。
- 系统设置、导出、摄像操作和记住账号在相应后端完成前保持禁用或明确说明。

## 运行

开发版：双击 `Run-Debug.cmd`。发布版：双击 `artifacts/release-package/tdlas_app.exe`。登录时任意非空账号和密码只创建本地界面会话，并由角色下拉框选择管理员或客户工作台；这不是生产认证规则。
