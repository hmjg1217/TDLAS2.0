# 第六步验收记录：旧算法审查迁移与未标定适配

日期：2026-10-28。工程：TDLAS2.0。按《实施计划》第 6 步审查并迁入旧 TDLASProcessor，完成独立处理目标、阶段诊断、跨块完整批次适配、v1.6 冻结输出对照和产品未标定边界。本轮没有接入 NI、磁盘存储或摄像，没有访问真实硬件。

## 完成内容

1. 新增 `tdlas_processing` 静态库，不从旧工程链接源码。`LegacyTdlasProcessor` 使用 C++17/STL 迁入旧 C++ 路径：四阶零相位低通、周期平均、峰值对齐、边缘区四阶基线、吸光度、旧频率偏移和 Voigt 坐标搜索。
2. 保留旧默认假设用于兼容回放：500 点/周期、20 周期平均、1 次光谱平均、10000 点窗口和 `+4.2 V`。调用方可显式提供其他窗口配置；窗口、平均乘积、内存预算、有限值及下标均先校验。
3. 修正旧实现的工程边界：处理区间末端夹在周期内；任意大读取块会依次处理全部完整窗口并保留尾部，不再只取最后一个窗口后清空；批次记录会话内首样本、首尾读取块和经偏移修正的起始时间。
4. `AcquisitionFrame` 新增有界 `processingDiagnostics`。每条诊断包含阶段、成功状态、原因和耗时；当前阶段为 input、low_pass、cycle_average、baseline、frequency_calibration、voigt_fit。空阶段或非有限/负耗时会在结果边界变为 Invalid。
5. 低通输入含 NaN、四阶基线点不足/矩阵奇异、Voigt 输入无可辨识正峰均返回明确失败阶段。算法失败生成 Invalid 完整批次，不伪造成功曲线或测量值。
6. `LegacyTdlasAdapter` 可直接作为 `AcquisitionRuntime::startWithResults` 的处理回调；只在处理线程调用。测试覆盖 300 点读取块跨越 800 点算法窗口、一个块参与相邻两个批次、37 点不完整尾部、输入身份/序号不连续和 Runtime 直接提交。
7. 成功算法回放仍标为 Uncalibrated。观测吸光度与拟合候选以周期内样本索引/无量纲保存；由于 FV 定义未确认，`frame.fv` 保持空，峰值历史断开；旧拟合峰和旧光强结果不写入产品 Metrics，浓度保持空。
8. UI 底部说明更新为“旧版算法回放适配层已接入；FV / 频率 / 光强 / 浓度标定未确认”。模拟源缺少已确认扫描边界，继续只走空结果回调，不用正弦电压冒充吸光度或 FV。

## 旧实现审查结论

旧源码中的以下数值只具有“实现来源”，没有足够资料证明其物理来源或适用范围：

- 交流信号统一加 `4.2 V`；
- 频率三次多项式；
- FSR `0.8761`、除数 `30.0` 和峰中心归零；
- 光强使用对齐周期最后一点与第 50 点之差，再除以 2 并乘 100；
- 把 Voigt 拟合曲线 `fv1` 同时当作 FV 和峰值来源；
- Voigt 初值、上下界和固定 80 次坐标搜索。

因此本轮只复现并诊断这些计算，没有把频率轴标为已校准 `cm^-1`，没有把拟合曲线发布为 FV，也没有发布旧光强百分比或浓度。`processingVersion`、基线方法、极性说明和模型标识均随批次保存，便于后续替换。

## 使用与复现

产品操作与第五步相同。选择模拟源只显示原始正弦电压，不出现 FV、峰值、光强或浓度。算法迁移验收只在测试进程的确定性回放夹具中运行。

在 TDLAS2.0 内执行：

```powershell
.\Build-Debug.cmd --no-pause
.\Build-Release.cmd --no-pause
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/ui-smoke.ps1 -Configuration Debug -Step 6
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/ui-smoke.ps1 -Configuration Release -Step 6
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/smoke.ps1 -Configuration Debug
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/smoke.ps1 -Configuration Release -Package
```

## 边界与后续

- 本轮“旧输出一致”仅针对旧 C++ 路径，不代表与 MATLAB `filtfilt`、`polyfit`、`lsqcurvefit` 完全等价。后续若以 MATLAB 为真值，需要提供固定原始样本、工具箱/版本和容差。
- 尚未确认完整物理扫描批次如何从真实 AI 流识别。第 8 步 NI 接入前后必须明确锯齿复位沿、采样率、周期重采样和停止时尾部策略，不能从显示点数推定。
- FV 定义、方向、单位、频率标定、I/I_ref、温压/光程和浓度公式仍待用户或标定资料确认；确认后应新增版本化校准配置与参考样本，而不是直接解除 Uncalibrated。
- 第 7 步可继续图表交互、CSV/JSON 和有界异步存储，但导出必须保留 processingVersion、质量、原因和诊断；未标定候选与有效测量必须可区分。
