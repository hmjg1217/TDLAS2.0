# TDLAS2.0 用户使用说明

版本：2.0.0。本文适用于整合后的 Windows x64 NI-DAQmx Release 可移植包。

## 1. 发布包与迁移

- 文件夹：`artifacts/TDLAS2.0-NI-DAQmx-Portable/`
- 压缩包：`artifacts/TDLAS2.0-NI-DAQmx-Portable.zip`

项目只提供 NI-DAQmx 启用版。迁移时复制整个文件夹，或在目标机完整解压 ZIP；不能只复制 `tdlas_app.exe`。目标机须为 64 位 Windows，并预先安装与采集卡兼容的 NI-DAQmx 驱动。Qt、FFmpeg、图形组件和 MSVC 运行库已随包部署；若目标机运行库损坏，可运行包内 `vc_redist.x64.exe` 修复。双击 `tdlas_app.exe` 启动。程序默认不会枚举 NI 设备、开始采集、输出 AO 或打开摄像头。

## 2. 登录与角色

登录页目前只建立本地界面会话：输入任意非空账号和密码，再选择角色即可进入。它不连接认证服务，也不构成安全授权。

- 管理员：显示客户窗口、调试界面、峰值数据和摄像界面四页。
- 客户：只显示客户工作台。

## 3. 模拟源

1. 在“采集卡（设备识别）”选择“模拟数据源（非测量）”。
2. 保持输出通道为 AI-only，检查采样率、显示点数和输入量程。
3. 点击“开始采集”；调试页显示确定性的模拟原始电压。
4. 点击“停止采集”，等待状态显示后台已停止。停止后曲线和统计会保留。
5. “复位”只清空内存中的当前会话；若已有数据会先确认，已完成的归档或导出文件不会被删除。

模拟源只验证软件链路，不表示氢气测量、标定或真实硬件已经通过。

## 4. NI 采集

1. 确认目标机安装 NI-DAQmx，设备接线、允许的 AI 量程、AO 电压和频率已经由现场负责人核准。
2. 点击“刷新 NI 设备”。刷新只读取设备能力，不创建采集或输出任务。
3. 选择运行时发现的设备和 AI 通道；不要依据历史记录假定设备名为 `Dev1`。
4. 不需要模拟输出时将输出通道留空（AI-only）。使用 AO 前再次核对输出通道、波形、频率、峰值幅值和偏移。
5. 手动开始，观察状态后再停止。错误或断连时等待后台完成安全清理，不要强制结束进程。

本发布轮次没有自动访问真实 NI 设备，也没有向真实 AO 输出电压。实机步骤必须由用户在现场手动执行。

## 5. 摄像头

1. 打开“摄像界面”，点击“刷新设备”。程序启动和进入页面本身不会请求或打开摄像头。
2. 选择实际 UVC 设备，点击“连接并预览”。
3. 预览就绪后可拍摄 PNG 或开始 MPEG-4 录像；停止录像后等待文件封装完成提示。
4. “数据保存”设置图片和录像目录；默认目录为 `data/camera/`。
5. “参数设置”提供数字平移/缩放、镜像/旋转、软件画质调校，以及设备支持时的硬件变焦、对焦、曝光和白平衡。禁用项表示当前设备未报告支持或尚未连接。
6. 离开客户/摄像预览页或关闭程序时，会先停止录像、完成封装并释放设备。

数字上下左右是裁剪视口平移，不是物理云台。软件画质调校影响预览和 PNG；当前录像仍使用相机原始 UVC 路径。

## 6. 数据、导出与完整性

- 原始数据：`data/raw-runs/<runId>/raw.csv` 和 `manifest.json`。只有完整提交后才标记为成功。
- 摄像文件：默认在 `data/camera/`。
- 峰值导出：峰值页的“导出 CSV + JSON”使用同一不可变结果快照；没有完整批次结果时按钮禁用。
- `SHA256SUMS.txt`：列出发布包文件的 SHA-256，可用于搬运后完整性核对。
- ZIP 旁的 `.sha256.txt`：用于核对整个压缩包在复制前后是否一致。

FV、频率标定、光强参考、浓度反演、温压/光程条件和有效范围尚未由项目确认。界面中的“未校准”“—”是有意的安全状态，不能替换为 0，也不能把旧算法回放值解释为有效测量。

## 7. 已知边界

- 登录不是生产认证；“系统设置”尚未实现。
- 自动化已验证模拟、Fake DAQ、合成摄像帧、存储、算法冻结回放和安全生命周期；不等于真实 NI 或真实摄像模组通过。
- 尚未完成真实 NI 通道/边界/断连/AO 验收，以及真实摄像权限、占用、分辨率/帧率、长时录像、丢帧、USB 断连验收。
- 仅在本机原生 125% DPI 显示环境完成截图核对；其他真实显示器/DPI 和读屏软件仍需现场人工验证。
