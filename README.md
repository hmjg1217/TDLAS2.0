当前阶段：第 0 步已完成（阅读、资料归档、分步计划）。尚未创建应用源码或可执行文件。

- [分步实施计划](docs/实施计划.md)：范围、顺序、验收和待确认事项。
- `references/`：本轮阅读的原始资料副本，仅供参考，不作为可执行入口。
- `references/manifest.json`：来源和 SHA-256 校验值。

按用户要求逐步实施，每轮完成一个明确步骤并报告验证结果，不一次完成全部功能。下一步为独立构建入口与最小可运行工程。

后续源码、构建输入、日志、测试数据、截图、发布包及开发用临时文件均放在本目录内。已安装的 Qt/MSVC/Windows SDK/NI SDK 继续作为外部工具链使用，不复制整个工具链。原 v1.5、v1.6 及其未提交改动保留。
